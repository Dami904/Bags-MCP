01 What is BagsMCP

The AI layer for the Bags.fm ecosystem.

BagsMCP is an MCP server that gives Claude native access to live Bags.fm data. You talk to Claude like a person — it handles the API calls, formats the data, and surfaces what matters.

Works in Claude Desktop, any MCP client, and directly in the browser — no install required.

02 Tools

6 tools. Real-time Solana data.

Claude calls these automatically when you ask the right question. No syntax. No commands.

🔥
get_trending_tokens
Top tokens on Bags.fm ranked by lifetime fees. Price, MCap, 24h stats for up to 50 tokens.
📊
get_token_info
Full market data — audit results, holder count, organic score, buy/sell breakdown, liquidity.
💰
get_token_price
Live USD and SOL price with 24h change and volume. Updated in real time.
💼
get_wallet_portfolio
Full token breakdown for any Solana wallet. See every position in plain language.
📜
get_recent_transactions
Last N on-chain transactions — status, timestamp, signature. Any public wallet.
🔄
prepare_swap
Swap quote via Bags.fm trade API. Estimated output, price impact, fees. Read-only — no execution.
