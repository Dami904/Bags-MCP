01 What is BagsMCP

The AI layer for the Bags.fm ecosystem.

BagsMCP is an MCP server that gives Claude native access to live Bags.fm data. You talk to Claude like a person ; it handles the API calls, formats the data, and surfaces what matters.

Works in Claude Desktop, any MCP client, and directly in the browser no install required.

04 Connect

One config.
Instant access.

Free and public — no token or signup required. Pick your platform and paste the config.

Works with all versions of Claude Desktop. Requires Node.js installed. 
{
  "mcpServers": {
    "bags": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://bags-mcp.onrender.com/mcp"]
    }
  }
}
npx downloads mcp-remote automatically on first run — nothing to install manually.
Open Cursor Settings → MCP and add a new server, or paste into ~/.cursor/mcp.json. 
{
  "bags": {
    "url": "https://bags-mcp.onrender.com/mcp"
  }
}
No token required. Restart Cursor after saving.

05 Bags Token

Earn fees with $BMCP.

BagsMCP is an AI research layer built on top of Bags.fm. Every time a user asks Claude to analyze a token, check a wallet, or get a swap quote — they're one step closer to trading on Bags.fm.

That trading activity generates swap fees. Bags.fm distributes those fees to token creators and holders. $BMCP holders earn a share of every swap that flows through the Bags.fm ecosystem.

Not required to use BagsMCP — but it aligns your incentives with the platform's growth.
