Connect to Claude Desktop — Free & Public

No token or signup required. Three ways to connect:

1 — EASIEST Settings UI — no config editing

Claude Desktop → Settings → Connectors → Add custom connector → paste this URL:

https://bags-mcp.onrender.com/mcp

Paste into your config file and restart Claude Desktop.

Windows: %APPDATA%\Claude\claude_desktop_config.json  ·  Mac: ~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "bags": {
      "url": "https://bags-mcp.onrender.com/mcp"
    }
  }
}

Use this if Method 2 shows "not valid MCP server configurations". Requires Node.js.

Windows: %APPDATA%\Claude\claude_desktop_config.json  ·  Mac: ~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "bags": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://bags-mcp.onrender.com/mcp"]
    }
  }
}

Cursor IDE

Settings → MCP → Add server, or paste into ~/.cursor/mcp.json:

{
